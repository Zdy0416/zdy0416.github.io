# 项目协作约定

- `Web/` 工作区只保留 `Zportfolio` 这一份最新版网站，包含当前未提交改动。旧 beta2 测试站、动画制作目录及 GSAP 原始分发包已移出工作区；后续直接维护本目录，不重建旧版本或在工作区堆放备份、制作中间文件、过期 QA 截图与报告。当前图片、视频、字体、`assets/vendor/`、运行依赖、Git 历史及发布配置必须保留。

- 用户说的「beta 版」是本机 `Zportfolio` 中最新的修改版本，包括尚未提交的改动。恢复 beta 预览时，启动当前源码，不回退代码。
- beta 预览固定使用 `http://127.0.0.1:5174/`，启动命令为 `pnpm dev --host 127.0.0.1 --port 5174 --strictPort`。
- 默认只修改和预览 beta 版。用户明确要求「发布线上版本」「更新 GitHub 网站」等发布操作后，才执行线上更新。
- 页面源码修改后，需要同步 `d` 中的页面片段；运行 `pnpm build` 会自动同步并生成本地产物，构建本身不发布网站。
- 首页仅保留两屏：01/ 标题首页和 02/ 螺旋作品展示。个人照片、个人介绍屏、首页底部联系屏和空白页脚已删除，不再恢复。首页桌面、平板和手机的下滑按钮均通过 `data-spiral-enter` 直接平滑进入作品展示；两屏之间无额外间距。
- 首页大标题为 “Design Portfolio”，沿用 PP Telegraf 字体、白色文字及原背景。
- 作品展示内嵌 WebGL 螺旋画廊，8 个项目统一维护在 `assets/project-catalog.json`；顶部和手机菜单 Projects 在首页进入第二屏，从详情页或联系页返回 `/#all-projects`。旧 `/projects` 地址只跳转到 `/#all-projects`。
- 作品区左上角圆形按钮为 Back to Home，点击及按 Esc / Home 返回标题首页。右下角 Connect 直接打开邮件，不滚动到已删除的联系屏。圆形按钮沿用 10rem、1px 白色细圆框和双圆磁吸效果。
- 作品区滚轮、拖动和方向键浏览项目，保留速度形变及项目封面的局部反色、噪声边缘和速度位移效果。触屏及减少动态效果偏好下不启用封面悬停特效。
- 音乐仅在作品区启用，离开、打开详情或退出首页时暂停；可手动开关。使用 `assets/unseen-backing.m4a`，来源为 Unseen 原 backing 音轨的 30.747166 秒循环段、160 Hz 低通滤波、30% 音量。左下角音乐按钮沿用五段声波造型，由 `assets/home-spiral.js` 发出 `portfolio:gallery-music` 事件控制单一播放器。
- 嵌入逻辑为 `assets/home-spiral.js`，使用 `assets/projects-webgl.js` 渲染器；`main.js` 的 section scroll bridge 对接首页虚拟滚动。自然滚动保留两段式入口，点击下滑按钮则直接进入。初始停在首页时不锁定滚动；返回首页后可再次进入。
- 已清理退役的独立 About 页、旧项目页和隐藏 capabilities 代码；不要重新引入旧模板、网格动效或历史封面。预载纹理由 `scripts/sync-page-data.mjs` 自动从现有图片属性和背景纹理生成。清理资源后运行 `pnpm check:assets`、`pnpm build` 和 `node scripts/check-assets.mjs dist`；仍被原生视频脚本动态创建的素材必须保留。

- 作品区左侧的 Showreel 卡片、环绕文字及视频弹层已按用户要求移除，不再恢复；左下角保留音乐开关。

- 虚拟滚动的每屏位移必须同步更新，即使直接跳到作品区或跨过整个视口，也要移走离开的屏幕；不能因目标位置已在视口外而跳过位移更新，否则首页标题会叠在项目画廊上。回归检查：`node scripts/check-section-scroll.mjs`。

- 全站页数标注只显示当前章节编号（如 `01/`、`02/`），不显示总页数（如 `/04`、`/05`、`01 // 04`）。首页和全部项目详情页遵循此规则；新增章节沿用当前编号，脚本只更新章节序号，不生成总页数。

- Combos 详情页第一屏保留全部文字：项目名、宣传大字、设计类别、技能及章节编号。第二屏右侧保留 GSAP 交互动画说明，下方展示三个可交互的星星 SVG；项目内容目前到 SVG 动画结束，不再保留其后的旧图片、视频及空白 03/04 章节。毛绒字母视频保持第二屏左侧，桌面区域约 42rem × 24rem，原第三屏的视频区已移除；网页素材为 `assets/combos-furry-letters.webm` 和 `assets/combos-furry-letters-hevc.mov`，透明背景、完整画面、静音自动循环、内联播放，不显示控制条，不提供放大、全屏或画中画入口。

- 星舵 `/project/kapsul` 保留 01/ 封面、02/ 完整 AR 演示视频。依据用户提供的 `星舵.pdf`，后续章节为 03/ 项目概览、04/ 核心玩法与手势交互、05/ 星球与关卡设计、06/ 3D 资产搭建、07/ 视觉语言与品牌规范、08/ UI 与交互界面、09/ 技术实现与空间体验。10/ 设计总结已按用户要求删除，项目内容到 09/ 结束。使用 PDF 提取的原始素材和可阅读的网页正文；每章 `data-pdf-pages` 标记来源页。已展示的关卡为糖果、沙漠、海洋三个，不将 PDF 中提及的其他主题写成已完成关卡。
